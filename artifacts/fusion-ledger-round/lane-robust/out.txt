To begin, first ensure that the latest run logs are available. This includes the most recent `keep` (30, default) and `older_than_days` (default 30) entries, along with the `prune` (30) and `older_than_days` parameters. If not, you will need to perform these operations manually. Then, use the `read_file` tool to view the current state of your persistent agent dir. You can check the current state by running `read_file shared/agent_dir/`, which will show the shared workspace and the current state of your agent dir.
